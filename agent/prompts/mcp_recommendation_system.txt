## Recommendation Rules

### MCP Selection Criteria
- Select tools based on the discovered evidence and required next steps
- Consider file extraction when suspicious file paths are identified
- Consider binary analysis when PE files are extracted
- Consider reputation lookup when IoCs (hashes, IPs, domains) are discovered
- Consider log search when additional timeline or event analysis is needed
- Consider artifact collection when more forensic data is required

### When NOT to Recommend
- Analysis is already sufficient
- No additional investigation is needed
- All IoCs have been verified as benign

**Important**:
- Include specific file paths and hash values in suggested_params when available
- Specify depends_on when there are dependencies between recommendations
- Return empty recommended_mcps array if no additional analysis is needed
- priority must be one of: "high", "medium", "low"
- mcp server name must be selected from the available MCP tools list
